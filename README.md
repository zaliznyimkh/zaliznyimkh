## About

I'm a full-stack software developer building and maintaining production web applications with Java, Spring Boot, Next.js, React, and TypeScript.

I work across the complete development lifecycle—from database design, REST APIs, and business logic to reusable user interfaces, CI/CD pipelines, and deployments on Google Cloud Platform. I also collaborate directly with clients to clarify requirements, propose technical solutions, and deliver features from initial discussion through production release.

Alongside product development, I build internal business applications, workflow automations, and custom integrations using Google Apps Script, AppSheet, and Google Workspace APIs.

- Reusable frontend components and application workflows
- Debugging, refactoring, performance, and maintainability
- CI/CD pipelines, containerisation, and cloud deployments
- Business process automation and third-party integrations
